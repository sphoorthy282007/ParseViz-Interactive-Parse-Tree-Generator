Elimination of Left Recursion Rules

Convert immediate left recursion of the form:

A -> Aα | β

Into the non-recursive form:

A -> βA'    and    A' -> αA' | ε

Indirect recursion (A ⇒ B… ⇒ A…) is removed first by substituting earlier non-terminals (Paull's algorithm).

Left Recursion Derivation
Elimination of Left Factoring Rules

If two or more productions of a non-terminal have the same prefix:

A -> αβ1 | αβ2 | … | γ

Left-factor it into:

A -> αA' | γ    and    A' -> β1 | β2 | …
Left Factoring Derivation
Rules for FIRST(X)
  • Rule 1: If X -> aα and a is a terminal, add a to FIRST(X).
  • Rule 2: If X -> ε, add ε to FIRST(X).
  • Rule 3: If X -> Y1Y2…Yk, add FIRST(Y1) − {ε}; if Y1 derives ε, continue with Y2, and so on. If all Yi derive ε, add ε.
Step-by-Step Solving: FIRST (productions that add each symbol)
Rules for FOLLOW(X)
  • Rule 1: Add $ to FOLLOW(start symbol).
  • Rule 2: For A -> α B β, add FIRST(β) − {ε} to FOLLOW(B).
  • Rule 3: For A -> α B, or A -> α B β with ε ∈ FIRST(β), add FOLLOW(A) to FOLLOW(B).
Step-by-Step Solving: FOLLOW
